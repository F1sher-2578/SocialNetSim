## 0. 背景定位：老师的参考系与本报告的补位

老师给的两个参考点：

1. **浙大 DFscan 深伪视频检测平台**——其流水线是 `切帧 → 人脸检测/裁剪 → 多专家模型并行打分 → 加权融合 → EER 阈值判定 → 可视化报告`，强调**跨生成器泛化性**与**对抗鲁棒性**。这条路线在 2024 年前是主流，但 2024–2026 出现了三个关键变化：(a) 伪造从"换脸"扩散到"整段 AIGC 生成"（Sora/Veo/Kling），人脸裁剪假设失效；(b) 音视频联合伪造成为主要威胁；(c) 检测器从"黑盒打分"转向"可解释 MLLM 推理"。
2. **Jiao et al., TNNLS 2022 的 video object detection survey**——该综述停留在 closed-set VOD（TransVOD 时代）。2023 年之后领域重心已整体迁移到 **open-vocabulary 检测 + 视频基础模型（SAM2）+ Video-LLM 时序定位**，逐帧闭集分类在审核场景下已不是主线。

本报告即针对这两处"时间差"补位。

## 1. 视频不良内容审核（violence / gore / porn / hate / 危险行为）

### 1.1 技术路线分类

### 1.5 对我们项目的具体建议（方向 1）

1. **不要做端到端训练**。2026 年 NOVA 已证明免训练能打过 2024 年监督 SOTA。我们在 M4 上训不动，也没必要训。
2. **分层审核（cascade）**：第 1 层 `Falconsai/nsfw_image_detection`（或 ShieldGemma 2）对**均匀采样的关键帧**做毫秒级粗筛 → 第 2 层只对触发帧的邻域窗口调用 Qwen3-VL-4B/8B 做细判与出解释。这能把 Video-LLM 调用量压到 5–10%，是 SafeWatch "policy-aware token pruning" 思想的工程平替。
3. **音频链路一定要接**。XD-Violence 的六类中 Explosion/Shooting/Riot 常常"声先于形"；`SenseVoiceSmall` 同时给 ASR 文本**和音频事件标签**，一个模型解决两件事，且中文最优。
4. **中文场景必用 MultiHateClip 的 Bilibili 子集**做评测——这是目前唯一有中文标注的仇恨视频公开基准，直接写进实验报告很有说服力。
5. **OCR 字幕不可忽略**：中文短视频大量有害语义在**硬字幕/贴纸文字**里。Qwen3-VL 的 OCR 能力较强，可在同一次调用内完成，不必另起 PaddleOCR（若要独立 OCR，PaddleOCR 在 Mac CPU 上可用）。

### 2.5 对我们项目的具体建议（方向 2）

2. **必须做跨生成器留一法（leave-one-generator-out）**，否则泛化性结论无效——这是 GenVideo 与 VidAudit 的核心方法论。
3. **压缩鲁棒性实验**：对同一视频做 CRF 23/30/40 的 H.264 重编码 + 720p→360p 降采样，画 AUC 随码率的衰减曲线。GenVideo 的"degraded video classification"任务就是干这个，成本极低但很出彩。
4. **不要试图训练深伪检测器**。改为"评测 + 融合 + 阈值校准（EER/DET 曲线）"，这在 M4 上完全可行。

### 3.3 ⭐ 核心问答：审核场景下"逐帧分类 + 时序聚合" vs "直接 Video-LLM 看整段"

| 维度 | A. 逐帧分类 + 时序聚合（CLIP/ViT + MIL/Transformer） | B. 直接 Video-LLM 看整段 |
|---|---|---|
| **准确率证据** | VadCLIP（冻结 CLIP + 双分支）UCF-Crime **88.02 AUC** / XD-Violence **84.51 AP**；2026 的 NOVA（CLIP 式训练免调 + 正常侧建模）**89.86 AUC / 95.07 AUC** | LAVAD 80.28、Holmes-VAD 84.61、VADor 85.90（均低于 VadCLIP）；VERA 在"可解释方法"内最高但仍需 InternVL2-8B。AIGC 检测上 Qwen2.5-VL 在 AEGIS 零样本仅 **22–23%** |
| **成本** | CLIP ViT-L 单帧前向约几十 ms（M4 MPS 可实时）；32 帧片段 < 1s | Qwen3-VL-8B 处理 32 帧，M4 上典型数秒~数十秒/片段；vision encoder 每次请求都要重跑（约 +1.5–2s） |
| **可解释性** | 只有分数曲线，无法回答"为什么" | 自然语言解释 + 时间定位，**审核申诉场景刚需** |
| **长视频** | 天然友好（滑窗 + MIL） | 受上下文限制，必须配采样器（Holmes-VAU 的 ATS、InternVideo2.5 的自适应采样） |
| **策略可变更性** | 改类别就要重训头 | **改 prompt 即可**，SafeWatch 就是靠这点做"自定义安全策略" |
| **失败模式** | 对"需要跨片段推理"的隐性有害（讽刺、诱导）完全无能 | 会"描述内容"而非"取证判断"（MM-Det 与 GenVideoLens 均指出此问题）；提示越复杂反而越差（紧凑 VLM 上 few-shot/CoT 会降 F1 并升延迟） |

**结论（也是我们的架构决策）**：**二者不是替代关系，而是级联关系。**
- 用 A 做**召回层**（便宜、帧级、可给分数曲线、长视频友好）；
- 用 B 做**判定与解释层**，只在 A 的高分窗口上触发（贵、但可解释、策略可变）。
- 这正是 SafeWatch 的 token 剪枝、Holmes-VAU 的 ATS、SlowFastVAD（arXiv:2504.10320，简单检测器 + RAG 增强 VLM）三篇论文各自独立给出的同一答案——**这个"三方印证"非常适合写进实验报告的方法论论证**。

### 3.4 对我们项目的具体建议（方向 3）

1. **采样策略分长短视频**：短视频（<60s）→ 均匀 1–2 fps 全覆盖；长视频（>5min）→ 先用 CLIP 帧相似度做**场景切分**，每场景取代表帧，再对高分场景密采样（InternVideo2.5 的 15fps/1fps 双档思路）。
2. **危险行为/危险物品**用 `grounding-dino-base` 开放词表 prompt（"knife", "gun", "fire", "blood"）而非训练闭集检测器——零训练、可改词表，写进报告就是"开放词表检测取代闭集 VOD"的直接演示。
3. **需要跟踪/计数时**再接 SAM 2 + ByteTrack，但注意这会显著增加 M4 负载，建议作为可选开关。

## 4. 检测器的对抗鲁棒性（AI Security 核心模块）

### 4.1 攻击面分类

| 攻击面 | 代表工作 | 关键点 |
|---|---|---|
| **对 CLIP/VLM 的对抗样本** | AnyAttack（CVPR 2025，大规模自监督对抗攻击）、Chain of Attack（CVPR 2025，迁移型） | CLIP 被 Zhao et al. 2023 / Schlarmann & Hein 2023 证明极脆弱，是整条审核链的单点故障 |
| **视觉越狱（Visual Jailbreak）** | Qi et al.（AAAI 2024，视觉对抗样本越狱对齐 LLM，奠基）、FigStep（排版提示越狱）、Jailbreak-in-Pieces（文本/OCR 文本/视觉/组合四类触发） | 把有害语义藏进图像，绕开文本 guardrail |
| **对审核分类器的规避** | NSFW 图像分类器的嵌入对齐扰动、SneakyPrompt、GhostPrompt（报告绕过 ShieldLM-7B 99.0% / InternVL2-2B 75.5%）；TokenBreak（分词层攻击） | 2025 的关键转变：**关键词级扰动对 LLM 型过滤器已失效，图像层伪影才是决定票** |
| **对深伪检测器的规避** | **StatAttack**（CVPR 2023，对抗统计一致性，奠基）、DeepEvader（2025，黑盒面部注意力分散）、Adversarial Reality（ICCVW 2025）、AADD-2025 挑战赛（ACM MM 2025） | AADD-2025 结论：**潜空间攻击 > 像素级攻击；集成策略提升跨模型鲁棒性；同时针对 CNN+Transformer 优化最有效** |
| **视频时序稀疏扰动** | SVASTIN（arXiv:2406.01894，时空可逆网络）、RLVS（IEEE TCSVT 2025，自注意力策略网选关键帧 + 仅估梯度符号）、STFAL（IEEE TCE 2025）、时间受限稀疏攻击（MVA 2025，含 temporal TV-L1 平滑项） | 利用视频时序冗余，**只扰动少数关键帧**即可；扰动会沿时序传播 |
| **压缩鲁棒性** | GenVideo 的 degraded task；RobustSora 的去水印基准 | 攻击者最省力的"攻击"其实就是重编码 |
| **音频对抗（对 Whisper/ASR）** | **Muting Whisper**（EMNLP 2024，0.64s 通用前缀即可静音）、**Controlling Whisper**（arXiv:2407.04482，强迫 Whisper 从转写切换到翻译）、Whisper Smarter not Harder（arXiv:2508.09994，部分抑制 + 指出**低通滤波是有效防御**）、Transferable Attacks against ASR（arXiv:2411.09220）、Acoustic Representation Optimization（arXiv:2503.19591） | 对我们的 ASR 审核链是直接威胁；跨架构迁移（Whisper→HuBERT/Wav2Vec2）仍困难 |

### 4.2 防御路线

| 防御 | 代表工作 | 成本 | 在 Mac 上可行性 |
|---|---|---|---|
| **对抗训练（AT）** | 视频频域弱到强时空一致性快速 AT（arXiv:2504.14921）；TeCoA（CLIP 零样本鲁棒微调） | 很高 | ❌ 24GB M4 不现实 |
| **扩散净化（DiffPure 系）** | DiffPure（NVlabs）、**VideoPure**（arXiv:2501.14999，首个视频扩散净化：时序 DDIM 反演 + 时空优化 + 多步投票，即插即用免重训）、ADBM（ICLR 2025，指出 DiffPure 次优性与"虚假安全感"） | 高（每图解 SDE） | ⚠️ 可小规模演示 |
| **随机平滑 / 认证鲁棒** | Consistency Purification（NeurIPS 2024，arXiv:2407.00623）、Adaptive Diffusion Denoised Smoothing（arXiv:2507.08163） | 极高（CIFAR N=10 万采样） | ❌ |
| **输入变换（JPEG / 比特深度 / 低通）** | 经典 feature squeezing；Whisper 场景的**低通滤波**被 arXiv:2508.09994 实证有效 | **极低** | ✅✅ **首选** |
| **特征压缩检测（feature squeezing）** | 比较原图与压缩图预测差异，差异大则判为对抗样本 | 极低 | ✅✅ |
| **集成 / 多专家融合** | AADD-2025 与 DFscan 架构一致 | 中 | ✅ |
| **跨模态主动防御** | Attack as Defense（EMNLP 2025 Findings，在视觉侧预埋保护性扰动；LLaVA-1.5 上把排版攻击 ASR 从 56.7%→12.6%，对抗扰动 89.0%→47.5%）、Tit-for-Tat（arXiv:2503.11619） | 中 | ⚠️ |
| **把反取证样本当第三类** | Frontiers in Big Data 2025 身份感知多分支网络（real / fake / anti-forensic 三分类） | 中 | ✅ 思路可借鉴 |

### 4.3 ⭐ 无 GPU Mac 上可复现的攻防实验设计（可直接照做）

**实验 A：白盒 FGSM/PGD 打穿 NSFW 分类器（1 小时内可跑完）**
- 目标模型：`Falconsai/nsfw_image_detection`（ViT-B，86M，MPS 上前向+反向都很快）
- 攻击：ε ∈ {1,2,4,8}/255 的 PGD-10，L∞
- 指标：攻击成功率 vs ε 曲线、LPIPS/SSIM 感知失真
- 产出：**ASR–失真权衡曲线**，这是对抗攻防最标准的图

**实验 B：时序稀疏攻击（体现"视频"特性，区别于图像作业）**
- 只扰动 K ∈ {1,2,4,8,32} 帧，其余帧不动，观察视频级判定何时翻转
- 对照 SVASTIN / RLVS 的核心主张"时序冗余使少数帧足够"
- 指标：翻转所需最小帧数 K*、单帧扰动预算

**实验 C：黑盒迁移攻击（更贴近真实威胁）**
- 代理模型 `Falconsai/nsfw_image_detection` → 目标模型 `Freepik/nsfw_image_detector` / `Marqo/nsfw-image-detection-384`
- 指标：迁移成功率矩阵（3×3 热力图）

**实验 D：轻量防御对比（Mac 友好，全 CPU 可跑）**
- 防御 1：JPEG 压缩（quality 75/50/30）
- 防御 2：比特深度缩减（8→5→4 bit）
- 防御 3：高斯模糊 / 中值滤波
- 防御 4：**特征压缩检测**——若 `|p(x) − p(squeeze(x))| > τ` 则判定为对抗样本，画 ROC
- 指标：干净准确率 vs 鲁棒准确率的帕累托前沿
- **注意**：报告中要诚实说明这些是"梯度混淆型"防御，在自适应攻击（BPDA/EOT）下会失效——引用 ADBM 对 DiffPure "虚假安全感"的批评

**实验 E：音频对抗（若时间允许）**
- 对 `FunAudioLLM/SenseVoiceSmall` 或 `openai/whisper-large-v3-turbo` 加通用前缀噪声，复现"静音攻击"
- 防御：低通滤波（arXiv:2508.09994 的实证结论）
- 指标：WER 变化

**实验 F：压缩鲁棒性（几乎零成本，但最贴近真实平台）**
- 对深伪/审核检测器输入做 H.264 CRF 23/30/40 + 分辨率降采样，画 AUC 衰减曲线

> ⚠️ **方法论警告（务必写进报告）**：DeepShip 官方从未公布 train/test 划分，导致文献准确率从 80% 到 99% 巨幅波动。**同一段录音的切片若同时出现在训练集和测试集会严重泄漏**。arXiv:2505.12904 采用 time-wise split 后准确率明显下降，但更贴近真实。凡看到 >97% 的数字，先查它用的是随机切片划分还是按录音/按船划分。

### 5.2 2023–2025 代表方法

| 路线 | 代表工作 | 要点 |
|---|---|---|
| **谱图 + CNN/Transformer** | DCMT（深度可分离卷积 + 多头 Transformer，DeepShip 97.53% / ShipsEar 98.19%，推理 3.8ms）；UACTC（卷积-Transformer 协同，ShipsEar 98.05% / DeepShip 96.96%）；HUATrans（Swin Transformer + 图像域迁移学习，ACM ICIVSP 2024） | Mel/LOFAR/DEMON 谱图为主输入 |
| **自监督 / 半监督** | Swin-based SSL（DeepShip 80.22%）；MHT-UATR（分层掩码 token 学习）；音频 SSL backbone 基准（SSAST / AudioMAE 等优于监督模型）；DART-MT（mean-teacher，10% 标注即 DeepShip 96.20% / ShipsEar 94.86%） | 解决标注稀缺 |
| **对比学习泛化嵌入** | arXiv:2505.12904 —— 采用 **time-wise split**，准确率下降但更真实 | 评测协议改良 |
| **自监督数据自动策展** | arXiv:2505.20066 —— DeepShip 预训练 + 双集微调优于监督 Transformer 基线；受限于海洋环境多样性不足 | |
| **参数高效微调** | Histogram-based PEFT for Passive/Active Sonar（arXiv:2504.15214） | **对 24GB Mac 最友好的一条路** |
| **对抗多任务鲁棒性（注意：是 adversarial learning，不是 adversarial attack）** | **AMTNet**：Xie, Xu, Ren, Li（中科院声学所），*JASA* 156(1):299–313, 2024；arXiv:2411.02848——把 source range / water column depth / wind speed 建为辅助任务并做对抗剥离，得到环境不变表征；ShipsEar 12 类 SOTA | |

### 5.3 针对 UATR 的对抗攻击与防御

| 工作 | 类型 | 要点 |
|---|---|---|
| **Adversarial Attacks in Underwater Acoustic Target Recognition with Deep Learning Models**（*Remote Sensing*） | **攻击（最直接对口）** | 在 **ShipsEar + DeepShip** 上对 4 个深度模型施加 **FGSM / PGD**；结论：PGD 强于 FGSM（准确率下降更快）；**MFCC 特征比 Mel-Fbank 更鲁棒**（作者归因于 MFCC 的 DCT 步骤把频率信息压到低维）；扰动越大越有效但越不隐蔽 |
| **Sonar-based Deep Learning in Underwater Robotics: Overview, Robustness and Challenges**（arXiv:2412.11840） | **综述（最佳入口）** | 系统梳理 FGSM/PGD 威胁模型 + 声呐专用攻防：ROSAR、NAN、LASA |
| **ROSAR: An Adversarial Re-Training Framework for Robust Side-Scan Sonar Object Detection**（arXiv:2410.10554） | **防御** | 用 PGD 攻击安全属性生成反例做对抗再训练 |
| **LASA (Lambertian-based Adversarial Sonar Attack)**（*Pattern Recognition*） | **物理可实现攻击** | 基于朗伯反射模型的侧扫声呐物理攻击；批评 FGSM 全局扰像素、不遵守声呐成像物理形成条件；可让 ResNet-101 把 "Shipwreck" 误判为 "Plane Wreckage" |
| **T-ADD: Enhancing DOA Estimation Robustness Against Adversarial Attacks**（arXiv:2512.10496） | 防御 | 阵列处理侧的 DOA 估计鲁棒性 |
| **Mirage Fools the Ear, Mute Hides the Truth**（arXiv:2510.02158） | 邻域攻击 | 对复音声音事件检测（SED）的精确定向攻击，可迁移思路到水声事件 |

> 🔍 **文献空白（可作为我们实验的创新点）**：2025 年**波形级**（而非图像级）被动声呐分类的对抗攻击+防御 arXiv 预印本非常稀少；多数 2025 声呐鲁棒性工作偏向侧扫/合成孔径**图像**。**在 ShipsEar 谱图上复现 FGSM/PGD 并对比 MFCC vs Mel-Fbank 的鲁棒性差异，是一个成本极低、但有真实文献支撑且尚未饱和的实验点。**

### 5.4 对我们项目的具体建议（方向 5）

1. UATR 与社交平台主线关系较远，建议作为**"对抗攻防方法论的跨域验证"**章节：证明同一套 FGSM/PGD + 输入变换防御的分析范式能迁移到完全不同的模态（声学谱图）。
2. 数据获取有邮件门槛，**提前 2 周发信**，用学校邮箱、注明仅研究用途。若来不及，可用公开的 UrbanSound8K / ESC-50 等替代做同构实验并说明。
3. 最小可行实验：Mel 谱图 → 小 CNN（几 M 参数，M4 上几分钟训完）→ FGSM/PGD 攻击 → 复现"MFCC 比 Mel-Fbank 鲁棒"的结论 → 加入输入变换防御。

### 6.1 主线架构（推荐，M4 24GB 可完整跑通）

                    │                                                  │

    ┌─────▼─────┐       ┌─────▼──────┐                   长视频>5min → CLIP场景切分
    │ 视频轨     │       │  音频轨     │                                +代表帧
    └─────┬─────┘       └─────┬──────┘

  └─ grounding-dino-base ["knife","gun","fire","blood"] → 危险物体
          │
      分数融合 + 时序聚合（滑窗 Top-K 均值 / MIL）
          │
     ┌────▼────┐  低分 → 直接放行（预计 90~95% 片段在此终止）
     │ 阈值判定 │
     └────┬────┘  高分窗口 ↓（只占 5~10%）
          │
【第2层 判定与解释（贵·秒级·片段级）】
  mlx-community/Qwen3-VL-8B-Instruct-4bit

  Prompt：可配置安全策略（SafeWatch 式）
  输出：{多标签类别, 严重度, 时间区间, 自然语言解释}
          │
【第3层 深伪/AIGC 取证（并行分支）】
  ├─ 专家A: prithivMLmods/Deep-Fake-Detector-v2-Model (人脸类)
  ├─ 专家B: 光流/时序二阶统计 (AIGVDet 思路，8帧降采样)
  └─ 专家C: Qwen3-VL-4B 伪影解释 (FakeVLM/SIDA 轻量平替)
          │  加权融合 + EER 阈值（对齐 DFscan 架构）

**为什么是这个组合？**

| 选择 | 理由（有证据） |
|---|---|
| 第1层用 CLIP + 轻量时序头而非 Video-LLM | VadCLIP 88.02 AUC > LAVAD 80.28 / Holmes-VAD 84.61；成本低 2–3 个数量级 |
| 第2层用 Qwen3-VL 而非 InternVL/VideoLLaMA | Qwen3-VL 有**显式文本时间戳对齐**（技术报告 arXiv:2511.21631），审核需要"几分几秒违规"；且 MLX 4bit 权重现成、中文最强 |
| 用 4bit MLX 而非 bf16 | 24GB 统一内存要同时容纳权重 + 视觉 token KV cache；8B-4bit ≈5GB 留足余量 |
| 音频用 SenseVoiceSmall 而非 Whisper | 中文/粤语更优，10s 音频 70ms（约 Whisper-Large 的 15×速度），且**同时输出音频事件标签**，一模型两用 |
| 级联而非单模型 | SafeWatch（token 剪枝）、Holmes-VAU（ATS 采样器）、SlowFastVAD（简单检测器+RAG VLM）三篇独立工作给出同一结论 |
| 深伪分支保留多专家加权 + EER | 直接对齐老师参考的 DFscan 架构，便于答辩讲解 |

### 6.2 备选方案

- **备选 A（极简 / 时间紧）**：`Falconsai NSFW` + `ShieldGemma 2-4b` + `SenseVoiceSmall` + 均匀采样 + Top-K 聚合。完全不用 Video-LLM，1 天可跑通，准确率够做 demo。
- **备选 B（追求可解释性上限）**：复现 **NOVA**（arXiv:2609.06360）的免训练零样本范式——正常侧提示构造 + 首帧视觉锚点。它在 UCF-Crime 达 89.86 AUC 且**完全免训练**，是 2026 年最新且最适合无 GPU 环境的方案，学术新颖度最高。
- **备选 C（如果拿到 GPU）**：微调 Holmes-VAU（HIVAU-70k 已开源）或用 SafeWatch 的策略并行编码复现自定义策略审核。

### 6.3 明确不建议做的事

- ❌ 端到端训练任何 VAD/深伪检测器（M4 训不动，且 2026 年免训练方法已反超）
- ❌ 追求单一"99% 准确率"数字（Deepfake-Eval-2024 证明这在真实流量上会掉一半，反而暴露方法论问题）
- ❌ 在 bf16 下加载 Llama-Guard-4-12B（≈24GB 权重，必 OOM）
